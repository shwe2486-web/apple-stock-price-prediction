# Apple Stock Price Forecasting

## Project Overview
This project predicts Apple stock prices using Time Series Forecasting and Deep Learning models.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- TensorFlow/Keras
- Scikit-learn

## Models Implemented
- ARIMA
- SARIMA
- SARIMAX
- LSTM
- GRU

## Project Workflow
1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Time Series Forecasting
5. Model Evaluation
6. Visualization

## Evaluation Metrics
- RMSE
- MAE

## Results
Compared multiple models to analyze forecasting accuracy and trend prediction.
